絆と記録  2026-09-27 確定（ゲームに入れ済み）

愛情度の段階で、図鑑に書き足される記録（3段階）と、絆で受け取る報酬（種族ごと）の作業用ファイル。
★ ここにあるのは下書き（Claude が書いたもの）。作者と、もう一つのAIで直す。
  決まったら Claude に渡す → data/monsters.js の records / bondReward に入れる。

▼ 記録の決まり（ストーリー構成.md の 10）
  出会い … いまの図鑑の説明文（スカウトしたときの記録）
  慣れ   … 生態の追記
  信頼   … 性格や癖の追記
  絆     … 愛着のにじむ一文
  主人公が書いた記録なので、最初は用心深く、深まるほど温度が上がる。
  絆の一文は、最初の記録（説明文）と呼応させると効く（「長く見ていたいものではない、と書いた。訂正する。」など）。
  1本は2行（1行19字くらい）までを目安に。図鑑の説明のあとに続けて出る。

▼ 絆の報酬の決まり（ストーリー構成.md の 10・affection.js）
  全員が専用技ではない。専用技の無い種族は、能力・耐性・既存の技。
  数値の強さではなく、その種族らしい効果で個性を出す。
  書き方：
    技を覚える … bondReward: { skill: "技のid" }（専用技は新しく作る）
    能力・耐性 … bondReward: { effects: [ ... ] }（特性・装備と同じ書き方。再生などの特殊な効果も使える）
    両方も可
  ★ 下の報酬の数値はすべて「案」。作者が決める。

▼ 専用技の数値の目安（いまの技との比較）
  基本技     … 威力15 / PP2（ファイア・アクアなど）
  特別枠     … サンダー 威力20 / PP3、シャイン 威力32 / PP5
  全体の息   … 威力15 / PP3（よけられない・クリティカルなし）
  回復       … キュア 35〜45 / PP2
  強化・弱体 … こうか・ちからぬき 3ターン / PP2〜3

 1. スライム（水・スライム系・最初の相棒）
================================================================
いまの説明：柔らかい体は打撃を吸い込み、傷もすぐに塞がる。見た目よりずっとしぶとい。

 慣れ：水辺では、ほかのスライムと体を寄せ合って眠る。冷えると少し固くなる。
 信頼：撫でられるのが好きで、手を止めると体を押しつけてくる。怒ると小さく震える。
 絆　：足元にいるのが、当たり前になった。この温かさを、もう怖いとは思わない。

 報酬：専用技「立ち塞がる」
