装備（data/items.js の equip を持つもの。43種）
================================================================

  装備枠：1体につき 武器1・防具1・アクセサリー2 の4つ（data/config.js の equipSlots）
    ・同じ装備は2つ着けられない
    ・枠が埋まっているときに別の装備を選ぶと、その枠の古いものと入れ替わる
  効果の掛かり方：計算式.txt の 1. と 2.
    statBonus     … 実効値に足す（個体値と同じ扱い。レベルで増えない）
    statMultiplier … 実効値に掛ける（レベルで増える）
    damageDealt / damageTaken … 与える／受けるダメージに掛ける（属性を書いたものはその属性だけ）
    resistBonus   … 耐性の数値そのものを上げる（+3 で倍率 0.3 ぶん軽くなる。合計 10 で無効）
  売値は買値の 50%（data/shop.js の sellRate）。落とす装備も同じ
  ★ 数値は「4枠を同時に着ける」前提
  ★ 第一章（揺籃の穴）はチュートリアル相当。装備はこの先もインフレさせる（作者の方針）

■ 組み合わせの目安（4枠を全部使ったとき）
  攻めの上限   若木の大剣(+33) + 毒沼の冠(+5) + 竜牙の指輪(+4) ＝ 攻+42（素早さ×0.9 の代償つき）
              代償なしなら 若枝の剣(+22) + 同じアクセサリー ＝ 攻+31
  守りの上限   苔甲の鎧(防+33) + 王冠の輪(防+3) ＝ 防+36。被ダメージを下げる装備は毒沼の冠(×0.95)だけ
  速さの上限   深淵の牙(速×1.1) + 若葉の羽飾り(+8) + 風切りの羽根(+7) ＝ 速+15 と 1.1倍
              速さを下げる装備は若木の大剣(×0.9)だけ（重い武器の代償。作者の指定）
  属性を尖らせる 燃え殻の剣(火)・粘晶の剣(水)・沼骨の槍(地)・若枝の剣(光)・若木の大剣(地) は武器、
              光る提灯・帯電の芯・風乗りの羽飾り・若葉の羽飾り・竜牙の指輪はアクセサリー。
              同じ属性の倍率は掛け算になる（若木の大剣×1.15 と 特性「大地の力」×1.25 で地 ×1.4375）

  ▼ 読み方
    ・statBonus はレベルで増えないので、序盤ほど効きが大きい。
      Lv25 では若葉の洞の装備の加算が素の能力値と同じくらいある（苔甲の鎧 防+33 で、敵の通常攻撃が 4〜7 まで落ちる）。
      Lv40 を過ぎると素の値が伸びて、加算の効きは薄れる。後半は倍率の装備（PP×1.2・速×1.1・属性×1.1）の価値が上がる。
    ・「攻+n」の値打ちは技と通常攻撃で違う（計算式.txt の 2.）。
      通常攻撃は ×0.75、技は種類ごと（共鳴 ×0.25・斬撃 ×0.65 など）。共鳴で戦う仲間には、攻撃加算より属性倍率が効く。
    ・「防御を上げる」と「被ダメージを下げる」は別物。防御は 0.30 を掛けて引く（共鳴・ブレスは 0.15）。
      被ダメ×0.95 はどんな攻撃でも 5% 減。相手の攻撃が強いほど後者が効く（主戦は後者）。
    ・耐性 +3 は倍率が 0.3 下がる（等倍 1.0 → 0.7）。弱点 -3（1.6倍）の仲間に着けると等倍に戻る。
    ・アクセサリー2つは「耐性＋属性」「速さ＋耐性」のように**方向を2つ持てる**のが利点。
