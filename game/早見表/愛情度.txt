愛情度（data/affection.js）
================================================================

  段階      必要な回数   報酬
  出会い        0        ―
  慣れ         30        全能力 +3%
  信頼         90        全能力 さらに +3%（合わせて +6%）
  絆          180        その種族だけの報酬（data/monsters.js の bondReward）

  全能力 = HP・攻撃・防御・素早さ・PP（倍率として掛かる。特性・装備と同じ仕組み）


▼ 上がり方
  ・勝った戦闘で、一度でも場に出ていた仲間に +1
  ・控え（場に出ていない仲間）には入らない
  ・逃げた・負けた・誘って終わった戦闘では増えない
  ・途中で倒れても、交代で出ても数える
  ・下がることはない。預けても残る

▼ 目安
  揺籃の穴1周ぶんの戦闘は、ざっと150〜300回。
  よく連れている仲間が、揺籃の穴を抜けたころに信頼、そのあと少し連れ回して絆へ届く。

▼ 見られる場所
  仲間の「様子を見る」の名前の下の札（愛情度 慣れ（34/60））。
  札を押す（または決定）と詳細の窓が開く：いまの段階・次までの残り・段階ごとの報酬。
  絆の報酬は、届くまで「？？？」と伏せる（hideBondRewardUntilReached）。

▼ 図鑑の記録
  その種族でいちばん深まった仲間の段階までの記録が、図鑑の説明文のあとに書き足される。
  図鑑（左のページ）では、まだ読めない段階も見出しと「？？？」で並ぶ（1.4.0）。
  仲間の「様子を見る」の「モンスター説明」のページでも読める。

▼ 種族ごとの報酬と記録
  記録と報酬があるのは30種（揺籃の穴 23・萌芽の穴 7＝若葉の洞 6・蔦這う回廊のコケキノコ）。本文と報酬は 絆と記録.txt。
  シニガミ・ツリガネ・ザンガルド（蔦這う回廊）は、まだ記録も報酬も無い。
  書き方：
    bondReward: { skill: "技のid" }                                         … 技を覚える（専用技でも既存の技でも）
    bondReward: { effects: [ { type: "statMultiplier", stat: "defense", value: 1.2 } ] } … 能力が上がる
    bondReward: { effects: [ { type: "resistBonus", element: "fire", value: 3 } ] }   … 耐性が上がる
    records: { used: "慣れの文", trust: "信頼の文", bond: "絆の文" }
  あとから書き足しても、もう絆に届いている仲間は次に読み込んだとき受け取る。
