■ 数値を変えるとき（data/abilities.js）
再生の10%・50   … regen の value と max
放電の20%       … discharge の chance
毒のとげの30%   … poisonThorn の chance
ねばねばの30%・×0.75・3ターン … stickyBody の chance と modifier（effects の value・duration）
吸精の10%       … soulDrain の value
脱皮の60%       … shedSkin の chance
追い風の2倍・2ターン … tailwind の value と turns
万全狩りの倍率  … fullHunt の tiers
