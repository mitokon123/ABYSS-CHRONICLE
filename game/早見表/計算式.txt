計算式 早見表（いまのゲームが使っている式）
================================================================

数字はすべて data/ の中にあり、コードには書いていない。
変えたいときは、各項目の最後の「置き場所」のファイルを直す。

  floor(x) … 小数点以下を切り捨てる     max(a,b) / min(a,b) … 大きいほう／小さいほう
  乱数(a〜b) … a 以上 b 以下のどれかがランダムに選ばれる

  目次
    1. 能力値          2. ダメージ        3. 属性の耐性      4. 命中・回避
    5. クリティカル    6. 行動順          7. 状態異常        8. 回復・PP
    9. 強化・弱体      10. 経験値・レベル 11. スカウト       12. 逃走・ドロップ
    13. 主（ボス）     14. 敵の行動       15. 作戦（仲間のAI） 16. 探索の仕掛け


================================================================
1. 能力値
================================================================

  HP・攻撃・防御・素早さ
    実効値 = floor( 基礎値 × (1 + 伸び) × 性格 × 効果の倍率 ) + 個体値 + 効果の加算
  PP
    最大PP = floor( 基礎PP × (1 + 伸び) × 効果の倍率 ) + 効果の加算　（性格と個体値は掛からない）

  最低 1・最高 9999（主など倍率の掛かった敵は止めない）

    基礎値       … 種族ごと（ステータス.txt）
    伸び         … Lv2 から今のレベルまで、1レベルごとの成長率を足したもの。
                   成長率は種族・能力ごとで、レベルの区切りで変わる（成長率.txt・成長率の段階.txt）。
                   書いていなければ 0.06
    性格         … 下の表
    個体値       … 生まれたときに決まる 0〜3
    効果の倍率・加算 … 特性・装備・愛情度・加護・強化／弱体をぜんぶ合わせたもの

  性格     HP    攻撃  防御  素早さ
    素直   1.00  1.00  1.00  1.00
    勇敢   1.00  1.10  0.90  1.00
    頑丈   1.10  0.90  1.10  0.90
    臆病   0.90  0.95  1.15  1.10
    俊敏   0.95  1.00  0.95  1.15

  例：基礎攻撃 20・成長率 0.10・Lv6・勇敢・個体値 2・装備なし
      20 × (1 + 5 × 0.10) × 1.1 = 33.0 → 33、＋2 で 35

  置き場所：data/growth.js（既定の成長率・上限）  data/monsters.js（基礎値・成長率）  data/natures.js

2. ダメージ
================================================================

  基礎
    技       基礎 = 攻撃力 × 〔攻撃係数〕 + 技の威力 × 〔威力係数〕 − 防御力 × 〔防御係数〕
    通常攻撃 基礎 = 攻撃力 × 0.75 + 3 − 防御力 × 0.30
    斬撃     基礎 = max(0, 通常攻撃の基礎) × 技の威力（倍率。噛みつく 1.15。2026-10-22 から）
    基礎 = max(0, 基礎)

    技の種類   攻撃係数  威力係数  防御係数
    共鳴       0.25      1.50      0.15
    ブレス     0.30      1.35      0.15
    体技       0.55      1.25      0.30
    踊り       0.40      1.35      0.30
    （斬撃     0.65      1.10      0.30 … 2026-10-22 までの斬撃の式。いまは死神の鎌だけがこれを使う）

  ダメージ = floor( 基礎 × 属性 × クリティカル × 防御コマンド × 特性・装備 × 乱数(0.9〜1.1) )

    属性          … 3. の倍率（弱点で最大 2.0、無効で 0）
    クリティカル  … 5.
    防御コマンド  … 相手が防御しているターンは 0.5
    特性・装備    … 攻める側の与ダメージ × 受ける側の被ダメージ × 相手のHPによる倍率 × ちからため
                    （呪いは被ダメージ 1.3。相手のHPによる倍率は特性「万全狩り」。
                     ちからため は次の通常攻撃・体技・斬撃だけ 1.85〜2.25倍。全体の技なら全員、二連斬りなら2回とも。
                     共鳴・ブレス・踊りには掛からず、ためた力はそのまま残る）

  何回か当てる技（二連斬り）… 1回ずつ 命中・回避・ダメージを判定する。相手が倒れたらそこで止まる
  歯車投げ                  … 1回ごとに相手をでたらめに選ぶ。相手が全員倒れるまで3回続く
  1回のダメージの上限      … 技の maxDamage（二連斬り＝200）。何回か当てる技は1回ずつに掛かる
  反動（捨て身の体当たり）  … 与えたダメージ × 1.0（最低1）を自分も受ける。倒れることもある

  0 になったら：40% で 1 だけ通り、残りは 0（0 のときは相手がのけぞらない）。属性が無効なら必ず 0

  例：攻撃 35・相手の防御 29・等倍・クリティカルなし・乱数 1.0
    通常攻撃            35×0.75 + 3 − 29×0.30           = 20.55 → 20
    ファイア（共鳴 15） 35×0.25 + 15×1.50 − 29×0.15     = 26.90 → 26
    噛みつく（斬撃 1.15）(35×0.75 + 3 − 29×0.30) × 1.15 = 23.63 → 23
    体当たり（体技 7）  35×0.55 +  7×1.25 − 29×0.30     = 19.30 → 19

  ▼ 読み方
    ・斬撃・体技は攻撃力がそのまま伸びる。共鳴は威力が頼りで、攻撃力の低い仲間でも戦える。
    ・斬撃は通常攻撃の何倍か。攻撃力が低い序盤は通常攻撃と大きく変わらず、終盤ほど差が開く。
      噛みつく・焔牙はクリティカルが出やすく、斬撃のクリティカルは防御を引かないので、そこが打つ価値になる（作者 2026-10-22）
    ・共鳴とブレスは防御を半分しか引かない。守りは防御より属性の耐性が中心になる。
    ・防御係数を上げると HP の大きい主の戦いに強く効く（0.35 で深層の主の勝率が 24% → 1%）。
      変えたら主の勝率を測り直す（balance-sim.html）。

  置き場所：data/battle.js（damage / critical / defend）  data/skills.js（威力・種類）

3. 属性の耐性
================================================================

  耐性 = 種族の耐性 + 装備・強化などの足し算　（-5〜+10 に収める）

    0 以上   … 倍率 = 1 − 耐性 × 0.10
    マイナス … 倍率 = 1 + |耐性| × 0.20
    +10      … 無効（ダメージ 0）

    耐性  -5   -3   -1    0   +1   +3   +5   +7   +9   +10
    倍率  2.0  1.6  1.2  1.0  0.9  0.7  0.5  0.3  0.1   0

  無属性（通常攻撃・体当たり・噛みつく など）は耐性の影響を受けない。
  状態異常の耐性も同じ表を使う（7.）。

  置き場所：data/battle.js（resistance）  data/monsters.js（resistances）


================================================================
4. 命中・回避
================================================================

  当たる確率 = 技の命中率 × 盲目（0.65）× 命中の強化・弱体（朧羽 0.8 など）
    盲目が掛かるのは通常攻撃・体技・斬撃だけ。共鳴・ブレス・踊りは盲目でも変わらない（朧羽は何にでも掛かる）
    技に命中率が書いていなければ 1.0
  当たったあと、相手の回避率でもう一度判定する（ほとんどの種族は 0。速い種族だけが持つ）
    自分・味方にかける技、ブレス、よけられない技（evadable: false）はかわされない
    相手全体の技はほとんどがよけられないが、ダメージを与える全体の体技（ルートスパイク・しんくうは）はよけられる（作者の決め）

  置き場所：data/skills.js（accuracy / evadable）  data/monsters.js（evasion）  data/statuses.js


================================================================
5. クリティカル
================================================================

  クリティカル率 = 0.03 + 技の criticalBonus + 種族の criticalBonus
    （種族の criticalBonus はいまザンガルドだけ 0.04 → 7%）
  出たとき
    ・ダメージ 1.66 倍。防御力を引かない（強化で上げた防御も）
    ・共鳴の技だけは 2.0 倍で、防御は引く
    ・属性の耐性・防御コマンド・特性や装備の軽減は、そのまま効く
  出ない技：相手全体の技・ブレス・canCritical: false の技
  主の行動の手順で「必ずクリティカル」と書いた手番は、必ず出る

  置き場所：data/battle.js（critical）  data/skills.js（criticalBonus / canCritical）  data/monsters.js（criticalBonus）


================================================================
6. 行動順
================================================================

  並べ替えの素早さ = 素早さ × 乱数(0.8〜1.2)　の大きい順。同じならランダム

  例外（上から強い）
    ・逃げる … 行動順の前にまとめて判定
    ・倒れた枠の交代 … だれよりも先
    ・防御・立ち塞がる … 素早さに関係なくターンの頭
    ・スカウト … 選んだ1体だけが最初に動く（ほかの味方の行動は防御以外消える）
    ・特性「先手」 … 最初のターンだけ先に動く（先手どうしは素早さ順）
    ・特性「追い風」… 戦闘の1〜2ターン目だけ、並べ替えの素早さが 2倍（能力値は変わらない）

  置き場所：data/battle.js（speedVariance / speedTieBreak）  data/abilities.js

7. 状態異常
================================================================

  かかる確率 = 技に書いた確率 × 耐性の倍率（3. の表。耐性 5 で半分、10 で無効）

  名前   続くターン  働き
  毒     治すまで    ターンの終わりに 最大HP × 0.125（上限 50）。探索中は 5 歩ごとに 1（HP は 1 で止まる）。
                     戦闘が終わっても残る（ほかは戦闘が終わると消える）
  麻痺   3〜5        毎ターン 50% で動けない
  眠り   2〜4        必ず動けない。ダメージを受けると 50% で目を覚ます
  封印   2〜5        共鳴の技が使えない（ほかの種類の技・通常攻撃はできる）。道具では治せない
  盲目   2〜4        命中率 0.65 倍
  呪い   3〜5        受けるダメージ 1.3 倍
  即死   ―          当たった時点で戦闘不能

  防御との関係
    ・眠っている者は防御できない。防御中に眠り・即死を受けると防御が解ける
    ・麻痺は五分：手番で動けたら防御が続き、動けなかったら解ける
    ・眠っている仲間のコマンドは「交代・そのまま・状態を見る」だけ。交代は状態異常で止められない

  防ぐもの
    ・芽吹きの守り（特性「芽吹き」）… 本当に掛かるときに1回だけ防ぐ（外れた分では減らない）
    ・状態異常の耐性を上げる装備・強化（9.）

  主に効かないもの
    全主共通：即死・封印・盲目
    主ごと：揺籃の穴の主4体は毒も、若葉の洞の主は毒と眠りも

  置き場所：data/statuses.js  data/skills.js（status）  data/monsters.js（statusResist）
            data/battle.js（bossImmuneToStatus）  data/bosses.js（immuneToStatus）


================================================================
8. 回復・PP
================================================================

  回復の技    … 技に書いた固定値（キュア 35〜45・キュアラ 75〜105 など）。攻撃力では変わらない
                 使う側の「回復の技 ×1.2」（粘晶のネックレスなど）が掛かる
  吸血        … 戻る HP = max(1, floor( 与えたダメージ × drain の割合 ))
  再生（特性）… ターンの終わりに 最大HP の 10%（1ターン 50 まで）
  若芽の護符  … 毎ターン 最大HP の 5%
  道具        … 薬草 20・回復薬 50・深淵の雫 100・精気の実 PP5
  蘇生        … 神鳥の羽：倒れた仲間1体を 最大HP の 55% で起こす（状態異常と強化・弱体は消える。戦闘・探索・拠点で使える）
  泉          … HP・PP を全回復し、状態異常も治す。倒れた仲間も起き上がる

  PPを減らす技（ミステリーダンス）… 相手のPPを 3〜7 減らす（残りが足りなければ残りぶん）

  置き場所：data/skills.js（heal / drain / ppDamage）  data/items.js  data/abilities.js  data/features.js

9. 強化・弱体
================================================================

  技に書いた効果が、書いたターン数だけ続く。ターンの最後にまとめて 1 減らすので、
  「3ターン」はかけたターンを含めて 3 ターン。同じものをかけ直すとターン数が戻るだけ（重ならない）。
  戦闘が終わると消える。効き方は 1. の「効果の倍率・加算」に入る（特性・装備と同じ）。

  変えられるもの：能力（倍率・加算）・与ダメージ・被ダメージ・命中・耐性
    例：こうか 防御 ×1.5／ちからぬき 攻撃 ×0.75／朧羽 命中 ×0.8／
        芽吹きの加護 味方全体の全状態異常の耐性 +4（3ターン）

  弱体への耐性
    相手に掛ける弱体は、入る確率 = 耐性の倍率（3. の表。5 で 50%、10 で無効）。入らなければ「MISS」。
    主は全員 5（data/battle.js の bossDebuffResist）。主ごとに data/bosses.js の debuffResist で変えられる。
    主以外（敵の在来種も仲間も）は全員 1（data/battle.js の debuffResistBase。90% で入る）。
    種族ごとに変えたいときは data/monsters.js に debuffResist を書く（いまは誰も書いていない）。
    味方に掛ける強化には関係しない。

  置き場所：data/skills.js（modifier）  data/battle.js（bossDebuffResist・debuffResistBase）

10. 経験値・レベル
================================================================

  次のレベルまでに要る経験値 = floor( 12 × Lv ^ 1.5 × 段階の倍率 )
    段階の倍率：Lv22 に上がる分から ×1.5、Lv50 から ×2.5、Lv80 から ×4
    Lv1→2：12　Lv5→6：134　Lv10→11：379　Lv20→21：1073　Lv21→22：1732
    Lv30→31：2957　Lv50→51：10606　Lv80→81：34346　（表は 経験値など.txt）

  倒したときにもらえる量
    経験値   = floor( 種族の expReward  × (1 + (相手のLv − 1) × 0.15) )
    ゴールド = floor( 種族の goldReward × (1 + (相手のLv − 1) × 0.15) )
  倒した敵ぜんいんぶんを合計し、倒れていない仲間ぜんいん（控えも含む）がそれぞれ全額もらう。
  ゴールドは合計をそのまま所持金へ。

  レベル上限：種族ごとの maxLevel（書いていなければ 50）。絶対の上限は 99
    いまは全種族 70 以上（作者 2026-10-28）。例外はシニガミの 1

  置き場所：data/growth.js  data/monsters.js（expReward / goldReward / maxLevel）


================================================================
11. スカウト
================================================================

  成功率 = 種族の scoutRate × (1 + (1 − 相手のHP割合) × 1.5) × 道具の倍率 × 持っている数の倍率
  1%〜95% に収める。HP満タンなら scoutRate のまま、HP 0 の直前で 2.5 倍

  持っている数の倍率（v1.0.3）：同じ種族をパーティと預かり所にあわせて何体持っているか
    0体 … 等倍　　1体 … 1/2　　2体以上 … 1/4
    逃がして数が減れば倍率も戻る

  例：scoutRate 0.20 の相手を HP 30% まで削る → 0.20 × (1 + 0.7 × 1.5) = 0.41 → 41%
      同じ種族を1体持っていれば 0.41 × 1/2 → 20.5%、2体なら 0.41 × 1/4 → 10.25%

  主を仲間にすると Lv1 になる（主としての倍率は外れる）

  置き場所：data/scout.js  data/monsters.js（scoutRate）


================================================================
12. 逃走・ドロップ
================================================================

  逃走の成功率：60%。主からは逃げられない
  ドロップ：種族の drops を1つずつ別々に判定（rate の確率で min〜max 個）。複数同時に落ちることもある

  置き場所：data/battle.js（fleeSuccessRate / bossCanFlee）  data/monsters.js（drops）


================================================================
13. 主（ボス）
================================================================

  主として立ちはだかるあいだだけ、能力値に倍率が掛かる（statMultiplier。1. の効果の倍率に入る）。
  仲間にすると外れ、その種族そのままの強さ（Lv1）になる。
  種族の基礎値を上げずに主を強くするための仕組み（基礎値を上げると、仲間にしたときまで強くなる）。
  倍率と実際の値は ステータス.txt。

  置き場所：data/bosses.js


================================================================
14. 敵の行動
================================================================

  技を使う確率：25%（種族に skillRate があればその値。出る場所の表に skillRate があればそれが最優先）。それ以外は通常攻撃
    選ばない技：PPが足りない・もう掛かっている自分への強化・全員満タンのときの回復
    種族に enemyAi.healBelow があれば、仲間のHPがその割合を切るまで回復技を使わない（ユラツボミ 30%）
  使う技：出る場所の表に skills があればそれ（蔦這う回廊）、次に種族の enemySkills、無ければ learnset（仲間にすると learnset に戻る）
  技ごとの選ばれやすさ：出る場所の表の skillWeights（例：ツリガネ デス 80・ゲイル 20）。書いていなければ同じ割合
    skillWeights には criticalAttack（必ずクリティカルの通常攻撃）も書ける（ザンガルド 稲妻斬り 75・criticalAttack 25）。
    これは通常攻撃なので PP が尽きても残る。PP が尽きて技が1つも使えなくなったら、技率に関係なく毎手番これになる（作者 2026-10-27）
  倒したときの経験値・ゴールド：出る場所の表に rewardMultiplier があれば掛ける（蔦這う回廊のカゲヅタ ×1.5）
  PPが減らない敵：出る場所の表の infinitePp（シニガミ）

  主は決まった順番（actionPattern）どおりに動く。1手ごとに次も書ける
    { skill: "normalAttack", critical: true }      … 必ずクリティカル
    { choice: [ { weight: 0.5, skill: "…" }, … ] } … 重みで1つ選ぶ（その手番ごとに引き直す）
  PPが足りない技の番は通常攻撃になるが、順番は進む

  狙う相手：盤面の左から 50% / 35% / 15%（2体なら 50 : 35 で割り直す）

  置き場所：data/battle.js（enemyAi / targetWeights）  data/monsters.js（skillRate / enemySkills / enemyAi）
            data/bosses.js（actionPattern）  data/dungeons.js（出現の表の skills / skillRate / skillWeights / infinitePp）


================================================================
15. 作戦（仲間のAI）
================================================================

  作戦で動く仲間は、コマンドを聞かれずに自分の番が来たとき行動を決める（防御だけはターンの頭）。
  使うのは 技・通常攻撃・防御 だけ。道具・スカウト・交代・逃げるは主人公。即死の技は使わない。
  上から順に見て、最初に当てはまったものをする：①回復 → ②状態異常を治す → ③補助 → ④攻撃

  作戦          回復する味方のHP     治す  補助  攻撃
  命令する      （コマンドで選ぶ）
  全力で攻める  25%未満              ―    ―    いちばん効く技
  仲間を守る    50%未満              ○    ―    いちばん効く技
  補助中心      25%未満              ―    ○    いちばん効く技
  PPを節約      30%未満（軽い技）    ―    ―    ふだん通常攻撃。倒せるときだけ技

  回復   … 減ったHPを全部埋められる技のうち回復量のいちばん小さいもの（無ければいちばん多く治すもの）。
           減った味方が2体以上で全体を治す技があれば全体。PPを節約はPPのいちばん軽いもの
  治す   … いちばん多く治せる技。掛かっている味方が2体以上なら全体の技（あれば）
  補助   … 強化 → 弱体 → 状態異常 を1手ずつ順番に、まだ掛かっていないものを使う
             強化：範囲＝効果量 ＞ 持続ターン
             弱体：効果量 ＞ 範囲 ＞ 持続ターン
             状態異常：持続ターン＝範囲 ＞ 効き（入る確率 × 相手の耐性）
  攻撃   … 2. の式で見積もったダメージ（クリティカルなし・乱数は真ん中・命中と回避も見る）がいちばん大きい技と相手。
           残りHPを超えるぶんは数えず、倒しきれる相手を少し高く見る。全体の技は全員ぶんを足す。同じならPPの軽いほう
  防御   … 自分のHPが 20% 未満で、自分では回復できず、ほかの仲間が回復の技を使えるとき（全力で攻める以外）

  置き場所：data/battle.js（tactics）  js/battle/BattleSystem.js（_chooseTacticAction）


================================================================
16. 探索の仕掛け
================================================================

  宝箱 … 中身を重み付きで1つ。どこでも：薬草 1.0・精気の実 0.3・回復薬 0.2。それにダンジョンごとの素材などが足される
  泉   … HP・PP を全回復し、状態異常も治す（倒れた仲間も起き上がる）。使うか選べる
  罠   … 仲間ぜんいんに 最大HP × 0.12 のダメージ（HP は 1 で止まる）

  1階に置く数：宝箱 1〜2・泉 0〜1・罠 1〜2（若葉の洞だけ宝箱 3〜4）

  置き場所：data/features.js  data/dungeon.js（featureCounts）  data/dungeons.js（featureTables / features）
