絆と記録（data/monsters.js の records / bondReward）
================================================================

  愛情度の段階で図鑑に書き足される記録（慣れ・信頼・絆）と、絆で受け取る報酬（種族ごと）。
  ゲームに出るのは data/monsters.js のほう。このファイルは読む・直すための控え（ゲームのデータから書き出したもの）。
  段階と必要な回数は 愛情度.txt。

▼ 記録の書き方（ストーリー構成.md の 10）
  出会い … 図鑑の説明文（図鑑説明文.txt）
  慣れ   … 生態の追記
  信頼   … 性格や癖・こちらへの振る舞いの追記
  絆     … 愛着のにじむ一文。いまの様子をそのまま書く
           ★「前は〇〇と書いた」「〇〇と書いた。訂正する」の形は使わない（作者 2026-10-28）
  主人公が書いた記録なので、最初は用心深く、深まるほど温度が上がる。
  1本は 38字くらいまで（2行）。図鑑の説明のあとに続けて出る。

▼ 報酬の決め方（ストーリー構成.md の 10・data/affection.js）
  全員が専用技ではない。専用技の無い種族は、能力・耐性・既存の技。数値の強さより、その種族らしさで個性を出す。
    技を覚える … bondReward: { skill: "技のid" }（専用技は data/skills.js に作る）
    能力・耐性 … bondReward: { effects: [ ... ] }（特性・装備と同じ書き方）
    両方も書ける
  専用技の数値の目安：基本技 威力15/PP2・回復 キュア35〜45/PP2・強化弱体 3ターン/PP2〜3
  （斬撃の技は威力が「通常攻撃の倍率」。噛みつく 1.15 が基本技くらい。2026-10-22 から）

▼ 専用技を持つ種族（9）
  スライム「立ち塞がる」・コウモリ「朧羽」・ヒカリムシ「導きの光」・キノコン「眠りの胞子」・
  キングスライム「王の号令」・フレイミン「焔牙」・ヌマボネ「青い眼光」・コダマ「芽吹きの加護」・
  ウェポン「烈火崩地斬」
  ※ 専用技はほかの種族に配らない（作者 2026-11-05。データの点検で「注意」に出る）

▼ 決まっていること
  ・ワカバドリの絆の文は、あとで風の共鳴の tier4「テンペスト」を覚える伏線（作者。技.txt）
  ・立ち塞がる … ターンの頭で立ち、そのターン向かい側からの攻撃をすべて受ける（全体技は全員ぶん受ける）。
                 麻痺・眠りで動けないとき、封印中は立てない。立った者が倒れたら、残りはふつうに当たる
  ・朧羽       … 盲目とは別の「命中の弱体」。両方掛かれば重なる。よけられない技・全体技にも効く
  ・絆の技は、図鑑の技の「覚えるモンスター」に「絆で覚える」と出る（届くまでは ??? のまま）
