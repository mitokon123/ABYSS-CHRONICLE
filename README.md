# ABYSS CHRONICLE

モンスターを仲間にしながら、毎回かたちの変わるダンジョンの奥を目指すゲームです。

## 遊び方

1. このページの緑の **Code** ボタン → **Download ZIP** でダウンロードする
2. ダウンロードした zip を右クリック → **すべて展開** する（zip を開いたままでは動きません）
3. 展開したフォルダの中の **`ABYSS CHRONICLE.html`** をダブルクリックする

ブラウザ（Chrome か Edge がおすすめ）で開きます。インストールは要りません。

## 操作

| 操作 | キー |
|---|---|
| 移動・選ぶ | 矢印キー / WASD |
| 決定 | Enter / Space / Z |
| 戻る | Esc / X |
| 仲間 | P / Tab |
| 持ち物 | I |
| 中断（ダンジョンの中） | F |

マウスでも遊べます。困ったときは、拠点の「遊び方」を見てください。

## セーブについて

セーブはブラウザの中に残ります。同じパソコンの同じブラウザで開けば続きから遊べます。
ブラウザの「閲覧データの削除」でサイトのデータを消すと、セーブも消えます。

## フォルダの中身

- `ABYSS CHRONICLE.html` … ゲームの入口
- `game/` … ゲーム本体と、作るときに使っている道具・資料（触らなくて大丈夫です）
